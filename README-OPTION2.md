# Prepwise — OpenAI Realtime Edition (Option 2)

This fork of [adrianhajdin/ai_mock_interviews](https://github.com/adrianhajdin/ai_mock_interviews) (Prepwise) **removes Vapi and Google Gemini entirely** and runs everything on your own OpenAI account:

| What | Before (upstream) | Now (this fork) |
| --- | --- | --- |
| Voice conversation | Vapi (~$0.09/min + platform fee) | **OpenAI Realtime API, WebRTC** (browser talks directly to OpenAI; ~$0.02–0.05/min on the mini model) |
| Question generation | Google Gemini | **gpt-4o-mini** (fractions of a cent) |
| Interview feedback | Google Gemini | **gpt-4o-mini** |
| Webhook / public URL needed | Yes (Vapi → your server) | **No** — everything runs in-app, works 100% on localhost |
| Auth & database | Firebase | Firebase (unchanged) |

## What changed in the code

- `app/api/realtime-session/route.ts` **(new)** — mints a short-lived (ephemeral) Realtime session token server-side. Your real `OPENAI_API_KEY` never reaches the browser; the browser only gets a ~2-minute token scoped to the Realtime API.
- `app/api/interviews/route.ts` **(new)** — creates interviews: generates questions with `gpt-4o-mini` and saves to Firestore (replaces the old Vapi webhook, now with login required).
- `components/Agent.tsx` **(rewritten)** — native WebRTC voice call (`RTCPeerConnection` + data channel) instead of the Vapi SDK. Collects the transcript for feedback, and for the "generate" flow it lets the assistant trigger interview creation via a function call, then takes you to the new interview.
- `constants/index.ts` — interviewer voice/prompts are now plain objects used by the Realtime session; voice is OpenAI's `sage`.
- `lib/actions/general.action.ts` — feedback now generated by `gpt-4o-mini`.
- Removed: `@vapi-ai/web`, `@ai-sdk/google`, `app/api/vapi/generate/route.ts`, `lib/vapi.sdk.ts`, `types/vapi.d.ts`.

## Setup (10 minutes)

### 0. Before anything: revoke exposed keys

If you ever pasted an API key or GitHub token into a chat (including with an AI), treat it as leaked and revoke it:

- OpenAI: https://platform.openai.com/api-keys → delete the old key
- GitHub: https://github.com/settings/tokens → delete the old token

Then create a **fresh** OpenAI key below. Never reuse or share keys — set a monthly spend limit on the OpenAI dashboard so a leak can never cost much.

### 1. Get the code

This zip is the **complete project** — the original Prepwise code with all Option 2 changes already applied. Just extract it:

- **Windows**: right-click the zip → *Extract All…* → open the extracted `prepwise-openai-realtime` folder
- **macOS / Linux**: `unzip prepwise-openai-realtime-full.zip && cd prepwise-openai-realtime`

No overlay, no patching, nothing to delete — the Vapi and Gemini files are already removed.

### 2. (Optional) Put it on your own GitHub

```bash
git init
git add -A
git commit -m "Prepwise with OpenAI Realtime API (WebRTC) + gpt-4o-mini"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/your-repo.git
git push -u origin main
```

### 3. Create a fresh OpenAI API key

1. Go to https://platform.openai.com/api-keys → **Create new secret key**.
2. Copy it somewhere safe (you'll paste it into `.env.local` — a local file that is never committed).
3. Optional but recommended: set a **monthly budget / spend limit** in the OpenAI dashboard.

### 4. Configure Firebase (skip if you already have it from the original setup)

1. https://console.firebase.google.com → **Add project** (free Spark plan is fine).
2. **Build → Authentication → Get started → Email/Password → Enable.**
3. **Build → Firestore Database → Create database** → start in **test mode** (or set rules to allow read/write for the `users`, `interviews`, `feedback` collections).
4. **Project settings (⚙) → General → Your apps → Web (</>)** → copy the config values → these are the `NEXT_PUBLIC_FIREBASE_*` vars.
5. **Project settings → Service accounts → Generate new private key** → open the JSON → these are the `FIREBASE_*` vars (`project_id`, `client_email`, `private_key`).

### 5. Set up `.env.local`

```bash
cp .env.local.example .env.local
```

Fill it in:

```env
OPENAI_API_KEY=sk-proj-your-new-never-shared-key
# optional overrides:
# OPENAI_REALTIME_MODEL=gpt-realtime-2.1-mini
# OPENAI_TRANSCRIBE_MODEL=gpt-transcribe

NEXT_PUBLIC_FIREBASE_API_KEY=...
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=...
NEXT_PUBLIC_FIREBASE_PROJECT_ID=...
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=...
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=...
NEXT_PUBLIC_FIREBASE_APP_ID=...

FIREBASE_PROJECT_ID=...
FIREBASE_CLIENT_EMAIL=...
FIREBASE_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\nMIIE...\n-----END PRIVATE KEY-----\n"
```

Notes:
- `FIREBASE_PRIVATE_KEY` must stay on **one line**, with `\n` where the real key has line breaks.
- `OPENAI_REALTIME_MODEL` is optional; default is `gpt-realtime-2.1-mini`. Change it to `gpt-realtime-2.1` if you want a smarter (pricier) interviewer.
- `OPENAI_TRANSCRIBE_MODEL` is optional; default is `gpt-transcribe` (used to transcribe your speech for the feedback page).

### 6. Install & run

```bash
npm install
npm run dev
```

Open http://localhost:3000 (use Chrome). Sign up with email/password, then:

1. Click **Start an Interview** → talk to Nexa: tell it the role, level, type, tech stack, number of questions → it creates the interview and takes you to it.
2. Click **Call** → answer out loud (allow the microphone when the browser asks) → **End** when done.
3. You land on the feedback page with scores, strengths and areas to improve.

## Cost cheat-sheet (approx.)

- Voice interview: ~$0.02–0.05 per minute on `gpt-realtime-2.1-mini` (+ ~$0.017/min for your speech transcription)
- A typical 10-minute mock interview ≈ $0.20–0.60
- Questions + feedback (gpt-4o-mini): less than $0.01 per interview
- So a $5 credit ≈ **several hours of practice**. Keep answers focused; end the call when done — billing stops when the call ends.

## Troubleshooting

| Problem | Fix |
| --- | --- |
| `Invalid URL (POST /v1/realtime/sessions)` | You are running the old beta code — this fork now uses the GA endpoints (`/v1/realtime/client_secrets` + `/v1/realtime/calls`). Re-copy the current files. |
| "The model ... was rejected" / `model not found` | Set `OPENAI_REALTIME_MODEL` in `.env.local` to a currently available Realtime model (check https://developers.openai.com/api/docs/models) and restart `npm run dev` |
| Transcription model error | Set `OPENAI_TRANSCRIBE_MODEL` in `.env.local` (default `gpt-transcribe`; `whisper-1` also works until Feb 2027) and restart |
| 401 / "Failed to start the session" | Check `OPENAI_API_KEY` in `.env.local`; check billing is active at https://platform.openai.com/settings/organization/billing |
| Microphone error | Click the lock/site-settings icon next to the address bar → allow microphone → reload |
| Firestore `permission-denied` | Firestore → Rules → make sure reads/writes are allowed (test mode), or allow the `users`, `interviews`, `feedback` collections |
| No sound from the interviewer | Make sure your speakers are on and the tab isn't muted (speaker icon in the tab) |
| "Failed to start the session" with `insufficient_quota` | Your OpenAI credit is used up — top up at https://platform.openai.com/settings/organization/billing |

## Security notes

- `.env.local` is git-ignored; never commit it, never paste its contents anywhere.
- The browser never sees your real OpenAI key — only short-lived ephemeral Realtime tokens minted by `/api/realtime-session`, which also requires a logged-in Firebase session.
- If a key ever leaks: revoke it at https://platform.openai.com/api-keys immediately. Deleting the message is not enough.
